# GOPACK — prototip začetne strani

Statična stran (HTML, CSS, JS), brez gradnje. Animacije: GSAP 3.12.5 + ScrollTrigger in Lenis 1.1.13 (CDN).
Podatki so z gopack.si. Obrazec za povpraševanje samo pripravi e-pošto (mailto), ne pošilja podatkov.

## Lokalno
Odprite `index.html` prek kateregakoli statičnega strežnika, npr. `npx serve .`

## Objava na Vercel
Uvozite repozitorij na vercel.com (Framework Preset: Other, brez Build Command, Output Directory: `.`).
